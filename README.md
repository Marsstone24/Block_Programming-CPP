# Block_Programming - C++
This project is written in `Rust` using `macroquad`. It is essentially to make programming `microcontrollers` easier, especially for children or teenagers that want to begin with this topic, but need more time to understand `C++`. Under the hood it is an `interpreter`, so it also can be used to learn **C++** visually.

## Main Features
- Programming in Blocks
- interpretation into **C++**
- reading what each block does in **C++**
